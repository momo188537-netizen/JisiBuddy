# 美术素材来源

鸡丝本人的头像（`JisiFace.png`、`JisiFaceMono.png`、App 图标）来自用户提供的照片，不属于下表。

| 文件（`JisiKit/Sources/JisiKit/Resources/`） | 原素材 | 来源 | 作者 | 许可证 | 改动 |
| --- | --- | --- | --- | --- | --- |
| `ItemYarn.png` | Yarn (3D) | https://github.com/microsoft/fluentui-emoji/tree/main/assets/Yarn/3D | Microsoft | MIT | 色相旋转为暖珊瑚色、略降饱和 |
| `ItemBox.png` | Package (3D) | https://github.com/microsoft/fluentui-emoji/tree/main/assets/Package/3D | Microsoft | MIT | 无 |
| `PropLaptop.png` | Laptop (3D) | https://github.com/microsoft/fluentui-emoji/tree/main/assets/Laptop/3D | Microsoft | MIT | 无 |
| `PropCoffee.png` | Hot beverage (3D) | https://github.com/microsoft/fluentui-emoji/tree/main/assets/Hot%20beverage/3D | Microsoft | MIT | 无 |
| `PropPlant.png` | Potted plant (3D) | https://github.com/microsoft/fluentui-emoji/tree/main/assets/Potted%20plant/3D | Microsoft | MIT | 无 |
| `PropWindow.png` | Window (3D) | https://github.com/microsoft/fluentui-emoji/tree/main/assets/Window/3D | Microsoft | MIT | 无 |
| `PropMoon.png` | Crescent moon (3D) | https://github.com/microsoft/fluentui-emoji/tree/main/assets/Crescent%20moon/3D | Microsoft | MIT | 无 |
| `PropStar.png` | Glowing star (3D) | https://github.com/microsoft/fluentui-emoji/tree/main/assets/Glowing%20star/3D | Microsoft | MIT | 无 |
| `PropGift.png` | Wrapped gift (3D) | https://github.com/microsoft/fluentui-emoji/tree/main/assets/Wrapped%20gift/3D | Microsoft | MIT | 无 |
| `PropFish.png` | Fish (3D) | https://github.com/microsoft/fluentui-emoji/tree/main/assets/Fish/3D | Microsoft | MIT | 无 |
| `PropFishingPole.png` | Fishing pole (3D) | https://github.com/microsoft/fluentui-emoji/tree/main/assets/Fishing%20pole/3D | Microsoft | MIT | 无 |
| `PropSparkles.png` | Sparkles (3D) | https://github.com/microsoft/fluentui-emoji/tree/main/assets/Sparkles/3D | Microsoft | MIT | 无 |
